# Proelium (배틀 중심 앱)

배포 주소 `/proelium/`. 포켓몬 3마리와 각자의 기술 4개를 **직접** 고르는 배틀 아레나입니다. 엔진은 `packages/rembrandt`.

## 디자인 방향
- **바탕은 순수한 검정**, 테마색은 **파랑(`#2a62ff`/`#9bb8ff`)과 금색(`#ffb21f`/`#ffe3a6`)** 두 가지입니다. 금색은 주요 버튼·강조·고리, 파랑은 조명·바닥 격자·보조 강조에 씁니다. 포켓몬 타입 색은 테마와 무관하게 유지합니다.
- **글꼴**: 강조(로고·제목·큰 글자)는 **Hahmlet**, 본문과 도감번호는 **Pretendard** (`tokens.css`의 `--display`, `--font`).
- **첫 화면**: 금색 고리가 돌고(빛줄기가 도는 고리, 반대로 도는 글자 고리, 궤도를 도는 빛 알갱이) 그 안에 로고와 팀 카드가 들어갑니다.
- **연출**: 화면 흔들림, 타격 파티클(타입 색 + 금색·파랑·흰색 등 여러 색), 데미지 숫자, K.O./효과 배너, 날씨 오버레이, 합성 효과음(WebAudio), 색종이.
- 토큰은 `src/styles/tokens.css`, 공용 부품은 `base.css`, 타입 색(18종)은 `dex.js`의 `TYPE_HEX`와 `tokens.css`의 `--t1..18`에 있습니다.

## 화면 흐름
홈 → 팀 편성(포켓몬 1,351마리 선택 · 기술 선택) → 매칭(VS) → 배틀 → 결과

| 파일 | 역할 |
|---|---|
| `src/main.js` | 화면 이동(`go`), 이미지 오류 대체, 효과음 |
| `src/dex.js` | 전체 포켓몬 목록·검색(이름·초성·도감번호), 폼 이름, 기술 풀, 추천 기술 |
| `src/store.js` | 저장(`proelium:` 접두어): 팀·난이도·전적·효과음 |
| `src/screens/*.js` | home · builder · matchup · battle · result |
| `src/sfx.js` · `src/fx.js` | 효과음 합성 · 색종이/토스트 |

## 데이터
- 기술 선택에는 포켓몬별로 배울 수 있는 공격기 전체가 필요해서, `packages/rembrandt/data/battle-learnsets.js`(`BATTLE_LEARN`)를 따로 만듭니다 (Holo는 불러오지 않음).
- 선택 가능한 기술 = 배우는 공격기 + 대표 공격기 + 변화기(270개) + 특수 공격기 포함 공격기 525개.
- 저장 키는 `proelium:` 접두어만 사용합니다 — Holo 와 도메인을 공유하기 때문.

## 개발
`npm run dev:proelium` (3001번 포트). 이미지는 PokeAPI 공식 일러스트를 쓰며, 불러오지 못하면 도감번호 자리표시로 바뀝니다.

## 배틀 기록 전송 (AI 개선용, 선택)

결과 화면(VICTORY/DEFEAT/DRAW)에서 **한 번 더 · 새 상대 · 팀 수정 · 홈** 중 하나를 누르면 그 판의 기록이 서버로 한 번 전송됩니다.
결과 화면 아래 체크박스를 끄면 보내지 않으며, 선택은 기억됩니다. 이름·계정·IP 등 개인정보는 담지 않습니다.

- **기록 내용(`schema: 1`)**: 시드, 난이도, 양쪽 파티(포켓몬 ID·기술), 단계별(`start`/`turn`/`replace`/`surrender`) 직전 상태(HP·상태이상·PP·필드·진영 효과)·내 행동·AI 행동·엔진 이벤트 전체, 결과. 한 판 약 10~60KB.
- **켜는 법**: 빌드 때 `VITE_LOG_ENDPOINT` 에 수집 주소를 넣습니다. 비어 있으면 체크박스도 안 보이고 아무것도 전송하지 않습니다. (GitHub Actions: 저장소 Variables 에 `LOG_ENDPOINT`)
- **수집 서버**: `tools/log-collector/` (Cloudflare Worker + KV). 배포 방법과 `/export?key=…` 내려받기는 `worker.js` 상단 주석 참고.
- **전송 실패 시**: 최근 5판까지 브라우저에 보관했다가 다음 전송 때 다시 시도합니다.
- 시드와 행동 기록이 있으므로 엔진(Rembrandt)으로 그대로 재현할 수 있습니다.
