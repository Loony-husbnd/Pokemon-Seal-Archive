# 포켓몬 띠부씰 컬렉션(v3.2)

포켓몬 띠부씰의 세대·속성·등급 정보를 기록하고, 실시간 통계와 도감 완성 예측을 보여주는 웹앱입니다.
수집한 포켓몬을 사육장에 넣어 상호작용할 수 있습니다.
등록 화면에서 메가진화·거다이맥스·리전폼·이로치 외에 **폼체인지**(기라티나(오리진폼), 쉐이미(스카이폼), 냐오닉스(암컷의 모습) 등 86종 411개 폼)도 선택할 수 있습니다.
`index.html` 한 파일로 동작하며, 데이터는 브라우저 저장소(localStorage)에 보관됩니다. 외부 API 키는 필요 없습니다.

## 실행 방법

- **바로 열기:** `index.html`을 브라우저로 열면 됩니다.
- **개발 서버 (선택):** Node.js 설치 후
  1. `npm install`
  2. `npm run dev` → http://localhost:3000
- **배포용 빌드:** `npm run build` → `dist/` 폴더를 정적 호스팅에 올리면 됩니다.

## 배틀 데이터 (개발 중)

3:3 배틀용 데이터(종족값, Lv100 능력치, 포켓몬별 대표 공격기 4개)는 `battle/data/battle-data.js`에 들어 있으며 생성 스크립트로 다시 만들 수 있습니다.

- `node tools/build-battle-data.mjs` — PokeAPI/Showdown 데이터를 내려받아 생성 (`--sample`, `--show 6,25`, `--explain=25` 옵션으로 결과 확인)
- `node tools/validate-battle-data.mjs` — 생성된 데이터 무결성 검증
- 능력치 가정: Lv100 · 개체값 31 · 노력치 0 · 성격 보정 없음
