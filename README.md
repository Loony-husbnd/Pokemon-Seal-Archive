# 포켓몬 띠부씰 컬렉션 (v4.0)

포켓몬 띠부씰의 세대·속성·등급 정보를 기록하고, 실시간 통계와 도감 완성 예측을 보여주는 웹앱입니다.
수집한 씰은 **바인더**처럼 펼쳐 볼 수 있고, **띠부파를레 사육장**에서 포켓몬과 교감하거나 **3:3 배틀**로 겨뤄 볼 수 있습니다.

`index.html` 한 파일(+ `battle/` 폴더)로 동작하며, 데이터는 브라우저 저장소(localStorage)에 보관됩니다. 별도 서버와 외부 API 키는 필요 없습니다.

## 실행 방법

- **바로 열기:** `index.html`을 브라우저로 열면 됩니다.
- **개발 서버 (선택):** Node.js 설치 후
  1. `npm install`
  2. `npm run dev` → http://localhost:3000
- **배포용 빌드:** `npm run build` → `dist/` 폴더를 정적 호스팅에 올리면 됩니다.
- **인터넷 연결:** 스타일·차트·아이콘 라이브러리(CDN)와 포켓몬 공식 일러스트 이미지를 외부에서 불러오므로 접속 환경이 필요합니다. 속성(타입) 정보는 내장 표를 우선 사용하고, 없을 때만 PokeAPI로 보완합니다.

## 도감 아카이브

### 1. 핵심 지표
상단 카드에서 다음 수치를 실시간으로 보여줍니다.

- 총 보유 수량 · 고유 종수
- 최다 보유 속성 TOP 1과 점유율
- 30주년 기념 씰 수와 전체 대비 비율
- 미개봉 수와 비율
- 도감 완성률(중복 제외, 1,025종 기준)
- 최고 수집 세대

### 2. 세대별 도감 완성률
1~9세대(관동·성도·호연·신오·하나·칼로스·알로라·가라르/히스이·팔데아)별로 공식 도감 수록 수 대비 몇 %를 모았는지 중복 제외 기준으로 집계합니다. 전국도감 전체 완성률도 함께 표시합니다.

### 3. 차트
- **세대별 현황:** 수집률(%) / 보유 수량 전환
- **18개 속성 분포:** 레이더 / 막대 차트 전환
- **등급 및 에디션 비율:** 미개봉·일반·하자, 그리고 씰 종류별 비율

### 4. 확률론적 도감 완성 예측 (CCP)
쿠폰 수집가 문제(Coupon Collector's Problem)를 이용한 예측 도구입니다. 모든 띠부씰의 출현 확률이 같다고 가정하고, 남은 도감을 모두 채우기 위한 기대 구매 횟수와 비용을 계산합니다.

- 기댓값: `E[X] = N × Σ(1/m)` (m = 1 ~ 남은 종수, N = 분석 범위의 총 종수)
- 분석 범위: 전체 1,025종 또는 세대별 선택
- 빵 1개 단가를 직접 입력할 수 있음 (기본 2,000원)
- 현재 수집 현황, 달성률, 남은 목표·비중, 추가 구매 기대치(봉지), 예상 추가 지출을 표시

### 5. 띠부씰 등록·수정
`새 띠부씰 등록` 버튼으로 엽니다.

- **도감 번호 입력 시 세대 자동 판별**, 포켓몬 이름 자동완성(**초성 검색** 지원: 예 `ㅍㅋㅊ`)
- **씰 종류:** 일반 / 레트로 / 30주년 / 30주년 오리지널 컬러, 30주년 기념 씰 여부 표시
- **상태 등급:** 미개봉 / 일반 / 하자
- **특수 폼 & 이로치**
  - 메가진화 (87종 · X/Y 구분 포함)
  - 거다이맥스 (32종)
  - 리전폼 (알로라·가라르·히스이·팔데아, 34개 폼)
  - 폼체인지 (기라티나(오리진폼), 쉐이미(스카이폼), 냐오닉스(암컷의 모습) 등 86종 411개 폼)
  - 이로치(Shiny) 표시
  - 선택한 폼에 맞는 이름과 공식 일러스트가 자동 반영됨
- **직전 등록 설정 기억:** 연속 등록할 때 씰 종류·등급이 유지되어 빠르게 입력할 수 있음
- 속성(타입)은 도감 번호로 자동 매핑 (듀얼 타입 지원)

### 6. 컬렉션 보기

**목록 보기**
- 카드 / 테이블 형태 전환
- 검색: 이름 또는 도감 번호
- 필터: 세대, 속성(18종), 상태 등급, 종류/에디션, 30주년 씰만
- 정렬: 도감 번호 오름/내림차순, 최근 등록순, 오래된 등록순, 이름순(가나다)
- 페이지 이동, 다중 선택 후 일괄 삭제
- 이미지를 눌러 확대(라이트박스)하고 상세 정보 확인

**바인더 보기**
- 전국도감 **18포켓 양면 바인더**(9+9 포켓)를 펼친 것처럼 표시, 총 57페이지
- 보유한 칸은 씰이 채워지고 미보유 칸은 빈 포켓으로 표시
- 이전/다음 페이지 버튼, **키보드 좌우 방향키**로 넘기기
- 페이지 번호 직접 입력, 이름·번호 빠른 검색 후 해당 칸으로 이동
- 세대별 빠른 이동 버튼
- 칸을 누르면 해당 도감 번호의 보유 목록을 보고, 한 장 더 추가하거나 삭제할 수 있음
- 마지막으로 본 보기 방식과 바인더 페이지를 기억함

## 띠부파를레 사육장

상단 **띠부파를레** 탭에서 수집한 포켓몬을 최대 **6마리**까지 사육장(글래스 테라스)에 데려올 수 있습니다. 탭 옆 배지에 현재 인원(예: `2/6`)이 표시됩니다.

- **엔트리 관리:** 도감에서 사육장 멤버를 추가·교체. `추천 6마리 등록`으로 한 번에 채울 수도 있음
- **시간대 배경:** 낮(06:00~17:00) · 노을(17:00~19:30) · 오로라 밤(19:30~06:00). `실시간`을 고르면 현재 시각에 따라 자동 전환되고, 직접 고정할 수도 있음. 햇살 입자·별·반딧불 같은 연출이 곁들여짐
- **테라스 생활:** 포켓몬이 돌아다니고 방향을 바꾸며, 말풍선으로 속마음을 말함
- **1:1 글래스 교감실:** 테라스의 포켓몬을 누르면 열림. 이전/다음 버튼으로 다른 멤버로 이동
  - **쓰다듬기:** 마우스 또는 손가락으로 약 3초간 문지르면 친밀도 상승 (완료 후 1초 대기)
  - **포켓몬빵 간식:** 돌아온 로켓단 초코롤 / 돌아온 고오스 초코케익 / 파이리의 화르륵 핫소스빵(이스터에그). 먹이면 포만감 +1, 친밀도 +8이며 포만감이 5/5이면 더 먹지 않음
  - **한마디 건네기:** 최대 30자 메시지를 보내면 포켓몬의 성격 유형(귀여운 타입, 의리 있는 타입, 전설·드래곤 타입 등)에 맞춰 대답함
- **친밀도 5단계:** 0~19 / 20~44 / 45~69 / 70~89 / 90 이상, 하트로 표시
- **파트너 인사 배너:** 사육장 멤버 중 한 마리가 시간대에 맞는 인사와 응원 메시지를 건넴. 닫으면 이번 접속 동안 숨겨짐
- 사육장 상태는 도감과 동기화되어, 삭제된 씰은 사육장에서도 정리됨

## 배틀

상단 **배틀** 탭에서 내 띠부씰 3마리로 AI와 3:3 턴제 배틀을 할 수 있습니다.

- **규칙**: 전원 Lv.100(개체값 31 · 노력치 0 · 성격 보정 없음), 포켓몬마다 대표 공격기 4개, 파티 종족값 합계 1,500 이하, 같은 종은 한 마리만. 특성·도구·날씨·변화기는 없습니다.
- **흐름**: 파티 편성(자동 편성 지원) → 난이도 선택(쉬움/보통/어려움) → 상대 파티 공개 → 배틀 → 결과(전적은 브라우저에 저장)
- **난이도**: 상대 파티의 종족값 합계가 내 파티 기준 −120 / 0 / +90으로 달라지고, AI의 실수율도 달라집니다.
- **조작**: 기술 버튼(또는 1~4 키) · 교체 · 항복 · 재생 속도(1~3x) · 연출 건너뛰기 · 전투 기록 · 상성 힌트 on/off

## 데이터 관리

상단 **데이터 관리** 메뉴에서 다음 작업을 할 수 있습니다.

| 메뉴 | 설명 |
|---|---|
| JSON 백업 내보내기 | 전체 컬렉션을 `pokemon_seals_backup.json`으로 저장 |
| JSON 파일 가져오기 | 백업 파일 복원. 파일 선택 또는 드래그 앤 드롭, **병합**(기존 데이터에 추가) / **덮어쓰기**(기존 데이터 교체) 중 선택 |
| 기존 데이터 타입 일괄 동기화 | 속성 정보가 누락된 포켓몬을 자동으로 채움 |
| 기본 샘플 데이터 로드 | 둘러보기용 샘플 씰 불러오기 |
| 전체 컬렉션 초기화 | 모든 씰 삭제 (확인 창이 뜸) |

- 가져오기 시 잘못된 항목은 걸러내고, 값을 검증·정규화하며, id 중복이 없도록 정리합니다.
- 이전 버전에서 저장된 데이터는 특수 폼 이름·이미지·타입 정보를 자동으로 보정합니다.
- 삭제나 초기화처럼 되돌릴 수 없는 작업은 확인 창을 거칩니다.
- 데이터는 **현재 브라우저에만** 저장됩니다. 브라우저 변경이나 사이트 데이터 삭제 전에 백업을 내려받아 두세요.

저장 키(localStorage): `pokemon_seal_db`(컬렉션), `pokemon_seal_habitat_v2`(사육장), `pokemon_seal_last_settings`(직전 등록 설정), `preferred_view_mode` · `preferred_binder_page`(보기 설정)이며, 배틀 전적도 브라우저에 저장됩니다.

## 기술 정보

- 구성: 순수 HTML/CSS/JavaScript 단일 페이지 앱 (빌드 도구는 Vite, 선택 사항)
- UI: Tailwind CSS(CDN) · Chart.js(차트) · Lucide(아이콘) · Pretendard(글꼴)
- 이미지: PokeAPI 공식 일러스트·스프라이트
- 배틀 모듈(`battle/`)은 일반 `<script>`로 불러오며, 빌드 시 `dist/battle/`로 복사됩니다.

## 개발자용

### 배틀 모듈 구조

| 파일 | 역할 |
|---|---|
| `battle/data/battle-data.js` | 종족값·Lv100 능력치·기술·상성표 (생성 파일) |
| `battle/engine.js` | 화면과 무관한 배틀 엔진 (데미지·상성·상태이상·교체 등). 사용법은 파일 상단 주석 |
| `battle/ai.js` | 규칙 기반 AI |
| `battle/party.js` | 파티 규칙 검증, 난이도별 상대 파티 생성 |
| `battle/ui.js`, `battle/battle.css` | 화면 (파티 편성, VS, 경기장, 결과) |
| `tools/` | 데이터 생성·검증·시뮬레이션 스크립트 |

### 스크립트

- `npm run battle:data` — PokeAPI/Showdown 데이터로 `battle-data.js` 재생성 (`--sample`, `--show 6,25`, `--explain=25`)
- `npm run battle:validate` — 데이터 무결성 검증
- `npm run test:battle` — 엔진·AI·파티 테스트 (44개)
- `npm run sim:battle` / `npm run sim:ai` — 대량 시뮬레이션(대칭성·밸런스 / 난이도 매트릭스)
- 시뮬레이션 결과 승패는 AI 판단보다 파티 능력치·상성의 영향이 커서, 난이도의 핵심은 상대 파티 강도입니다.
- `npm run build` 시 `battle/` 폴더가 `dist/battle/`로 복사됩니다.
